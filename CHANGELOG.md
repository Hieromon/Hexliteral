# Change Log

## [Unreleased]

## [1.0.0] - 2026-11-05

### Added

- Convert file to hexadecimal byte array

## [1.1.0] - 2026-11-06

### Added

- Introduced the `hexliteral.showInContextMenu` configuration to toggle the visibility of Hexliteral commands in the Explorer context menu.
- Context menu commands are now opt-in (default: `false`) to keep the Explorer environment clean by default.
